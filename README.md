# DW2 · Resource Library（资源分类）

**联合署名：S.A. · DW2**  
**版本：v0.1.17-beta.1｜适用于 TauriTavern / SillyTavern 1.16.0+ 的实验性扩展**

这是一个**独立、可关闭、非破坏性**的资源分组测试版。不会修改、删除或重命名任何原始预设、世界书或美化主题文件。

## 设计原则

- **日常入口跟随酒馆主题**：在 TT 原本的预设 / 角色卡世界书编辑 / 美化下拉框原位显示一个带细箭头的分组选择框。全局世界书可单独启用原生 Select2 下拉内分类，默认关闭。
- **总面板独立**：通过魔法棒「资源分类」或扩展设置「打开资源整理」进入独立的 Private Atelier 暖灰棕玻璃管理面板。
- **全中文、轻量**：主入口只展示「预设 / 世界书 / 美化」三类；少量跨 API 的具体预设类型在选择来源时用中文解释。
- **只保存分类**：自定义分类、分类分配记录保存在酒馆当前用户的 `extensionSettings.dw2ResourceLibrary` 中。资源选择仍委托 TT 原生 `<select>` 的 `change` 事件。

## v0.1.9-beta.1 · 分类删除后刷新不再复活

- 修复 **删除分组并刷新 TT 后，旧文件夹重新出现**：停用每次启动都把废弃的 `world:global` 数据重新合并进编辑世界书的逻辑。旧全局数据保留作历史备份；仅当用户从未建立编辑世界书分类时，才允许**一次性迁移**。已经整理过（包括删除为空）的编辑分类绝不会被旧数据覆盖或复活。
- 修复另一种复活：删除/改名了手动的「【名称】」系列分组后，自动识别会按旧名称又新建一个。现在按资源类型保存 `suppressedAutoGroups`（用户明确删除的分类名），不再让自动识别、智能整理偷偷重新建立；手动再次创建同名分类会解除屏蔽。
- 删除、改名、新建分类立即尝试刷新 TT 的延迟设置写盘队列；点击资源库自己的「刷新酒馆」时等待待保存设置完成（不支持 flush 的 TT 版本有短暂等待）。
- 修正使用世界书稳定名称键后，智能整理预览中的「剩余未分类数量」仍按旧选择序号计算的问题。
- 加入多轮重启、旧全局数据、删除/改名、自动前缀、智能整理与 UI 交互回归检查。原始资源、其他 DW2 插件及资源库玻璃外观不变。
- 旧分类历史仍留在迁移备份中，不作为活跃分类重新注入。用户需主动「新建分类」才能再次使用被删除的同名组。

- 未删除、重命名或修改任何预设、世界书、美化主题本体，不影响已有 DW2 插件。

## 测试版功能

- 原位按组折叠选择预设、主题及世界书；搜索资源名称或分组名称。
- 自动识别名字前缀 `【分组】`、`[分组]`，只有同组至少两条才自动成组；管理面板可以通过「智能整理」预览后把确定的系列整理为稳定分类。
- 管理面板创建、重命名、删除自定义分类，并为资源指定分类。
- 导出分类备份 JSON；**暂不支持导入**（避免尚未经过实机验证的覆盖操作）。
- 关闭「启用原位分组选择」，移除自定义控件并恢复原生选择框。
- 初次安装默认关闭接管开关；可以先打开总面板查看说明，再按需开启。
- 检测到「嘎嘎资源分组」仍在页面运行时拒绝接管选择器，避免两个插件同时争抢同一位置。

## 使用方法

1. **先停用「嘎嘎资源分组」并刷新 TT。** 两款插件不应同时接管原生下拉框。
2. 在「扩展设置」打开 **✧ DW2 · Resource Library**，勾选「启用原位分组选择」。
3. 进入 TT 的预设、世界书或美化设置页。点当前资源选择框，即可搜索和展开分组。
4. 打开魔法棒「资源分类」，可新建文件夹、归类、重命名或导出分类备份。
5. 如发现原生选择受影响，立即取消勾选「启用原位分组选择」，恢复 TT 原始控件。

## 测试版边界与注意事项

- 与嘎嘎、其他下拉框替换类插件不要同时运行。若仍检测到嘎嘎运行，会阻止接管。
- 世界书「全局启用」和「编辑选择」保留两种不同的资源选择动作，但共享同一份文件夹分类记录，不混淆启用状态与编辑状态。
- 具体 TT 版本、主题、世界书 Select2 组件可能存在差异，**本地模拟浏览器测试通过不代表 iOS / Android TT 实机已通过**。
- 本扩展不提供删除预设、删除主题、删除世界书，也不触碰聊天或存档内容。
- 版权归 `S.A. · DW2`。独立实现了这一版本的逻辑，没有复制第三方插件的源码。公开发布时请由仓库所有者决定许可证。
