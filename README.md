# DW2 · Resource Library（资源分类）

**联合署名：S.A. · DW2**  
**版本：v0.1.2-beta.1｜适用于 TauriTavern / SillyTavern 1.16.0+ 的实验性扩展**

这是一个**独立、可关闭、非破坏性**的资源分组测试版。不会修改、删除或重命名任何原始预设、世界书或美化主题文件。

## 设计原则

- **日常入口跟随酒馆主题**：在 TT 原本的预设 / 世界书 / 美化下拉框原位显示一个带细箭头的分组选择框。避免两层原生下拉框同时显示。
- **总面板独立**：通过魔法棒「资源分类」或扩展设置「打开资源整理」进入 Clear Mist 清透烟雾玻璃管理面板。
- **全中文、轻量**：主入口只展示「预设 / 世界书 / 美化」三类；少量跨 API 的具体预设类型在选择来源时用中文解释。
- **只保存分类**：自定义分类、分类分配记录保存在酒馆当前用户的 `extensionSettings.dw2ResourceLibrary` 中。资源选择仍委托 TT 原生 `<select>` 的 `change` 事件。

## v0.1.2-beta.1 · 文件夹展开与移动端交互修复

- 总面板正式支持文件夹展开／折叠，在各文件夹下直接查看和移动资源；「未分类」固定显示在最后，即使数量为零也不隐藏。
- 分类数量基于当前选择器内的实际资源计算，不再只显示手动分配记录。
- iOS/TT 原位弹层补全 touchmove / pointermove / mousedown / wheel 等事件隔离，降低触摸被 TT 外层设置页接管的风险。保持原生滚动能力，不拦截默认触摸行为。
- 智能整理增强对 iOS 主题色系列、中文系列版本和版本标记的识别；仍然采用先预览确认，再写入分类记录的策略。
- 手动分组优先，不动原始预设、世界书、美化。**需要 iOS/Android 实机重新验证原位展开行为。**

## v0.1.1-beta.1 · 实机反馈修复

- **总面板**使用更扎实的 Clear Mist 冷烟灰底板，提高渐变不透明度，背景不再穿透得太明显。
- **原位弹层**修复 iOS/TT 上点击「未分组」展开时，事件传到酒馆外部并收起设置页的问题；若原选择器本身不可见，自动关闭孤立弹层。
- **智能整理（预览后确认）**：根据显式 `【标签】`、`[标签]`、同名系列版本等保守规则建议分组，显示整理数量，确认后只保存分类信息；已手动归类条目原样保留。
- 未删除、重命名或修改任何预设、世界书、美化主题本体，不影响已有 DW2 插件。

## 测试版功能

- 原位按组折叠选择预设、主题及世界书；搜索资源名称或分组名称。
- 自动识别名字前缀 `【分组】`、`[分组]`，只有同组至少两条才自动成组；管理面板可以通过「智能整理」预览后把确定的系列整理为稳定分类。
- 管理面板创建、重命名、删除自定义分类，并为资源指定分类。
- 导出分类备份 JSON；**暂不支持导入**（避免尚未经过实机验证的覆盖操作）。
- 关闭「启用原位分组选择」，移除自定义控件并恢复原生选择框。
- 初次安装默认关闭接管开关；可以先打开总面板查看说明，再按需开启。
- 检测到「嘎嘎资源分组」仍在页面运行时拒绝接管选择器，避免两个插件同时争抢同一位置。

## 使用方法

1. **先停用「嘎嘎资源分组」并刷新 TT。** 两款插件不应同时接管原生下拉框。
2. 在「扩展设置」打开 **✧ DW2 · Resource Library**，勾选「启用原位分组选择」。
3. 进入 TT 的预设、世界书或美化设置页。点当前资源选择框，即可搜索和展开分组。
4. 打开魔法棒「资源分类」，可新建文件夹、归类、重命名或导出分类备份。
5. 如发现原生选择受影响，立即取消勾选「启用原位分组选择」，恢复 TT 原始控件。

## GitHub 一键安装（TT / SillyTavern）

已经发布到独立仓库：

```text
https://github.com/dw2devil1024-creator/dw2-resource-library
```

1. 打开 TT 的「扩展」→「安装扩展」，粘贴上述 GitHub 地址。
2. 安装选「仅自己安装」即可；与此前的全局安装路径保持一致时，也可以按自己原有的安装方式选择。**不要在同一账号同时安装全局版和用户版两份相同扩展。**
3. 安装后刷新 TT，在「扩展设置」找到「✧ DW2 · Resource Library」。
4. **先停用嘎嘎资源分组并刷新酒馆，再打开「启用原位分组选择」测试。**

需要恢复原生下拉框时：关闭「启用原位分组选择」，分组数据仍保留；如遇兼容性问题，也可在「管理扩展」里禁用整套扩展。

`tests/` 与 `package.json` 是开发和自测文件，不影响 TT 运行。

## 测试版边界与注意事项

- 与嘎嘎、其他下拉框替换类插件不要同时运行。若仍检测到嘎嘎运行，会阻止接管。
- 世界书的「全局启用」和「编辑选择」暂时是两种来源，分类独立保存。后续可视实机表现考虑共享文件夹。
- 具体 TT 版本、主题、世界书 Select2 组件可能存在差异，**本地模拟浏览器测试通过不代表 iOS / Android TT 实机已通过**。
- 本扩展不提供删除预设、删除主题、删除世界书，也不触碰聊天或存档内容。
- 版权归 `S.A. · DW2`。独立实现了这一版本的逻辑，没有复制第三方插件的源码。公开发布时请由仓库所有者决定许可证。
