# DW2 · Resource Library（资源分类）

**联合署名：S.A. · DW2**  
**版本：v0.1.31-beta.1｜适用于 TauriTavern / SillyTavern 1.16.0+ 的实验性扩展**

这是一个**独立、可关闭、非破坏性**的资源分组测试版。不会修改、删除或重命名任何原始预设、世界书或美化主题文件。

## 设计原则

- **日常入口跟随酒馆主题**：在 TT 原本的预设 / 角色卡世界书编辑 / 美化下拉框原位显示一个带细箭头的分组选择框。全局世界书可单独启用原生 Select2 下拉内分类，默认关闭。
- **总面板独立**：通过魔法棒「资源分类」或扩展设置「打开资源整理」进入独立的 Private Atelier 暖灰棕玻璃管理面板。
- **全中文、轻量**：主入口只展示「预设 / 世界书 / 美化」三类；少量跨 API 的具体预设类型在选择来源时用中文解释。
- **只保存分类**：自定义分类、分类分配记录保存在酒馆当前用户的 `extensionSettings.dw2ResourceLibrary` 中。资源选择仍委托 TT 原生 `<select>` 的 `change` 事件。

## 使用方法

1. **先停用「嘎嘎资源分组」并刷新 TT。** 两款插件不应同时接管原生下拉框。
2. 在「扩展设置」打开 **✧ DW2 · Resource Library**，勾选「启用原位分组选择」。
3. 进入 TT 的预设、世界书或美化设置页。点当前资源选择框，即可搜索和展开分组。
4. 打开魔法棒「资源分类」，可新建文件夹、归类、重命名或导出分类备份。
5. 如发现原生选择受影响，立即取消勾选「启用原位分组选择」，恢复 TT 原始控件。
